# Messprotokoll M4 — LiDAR-Tiefe gegen Maßband

Rohdaten: `data/measurements/m4/*.csv`, eine Datei je App-Export
(`m4_lidar.py` liest den ganzen Ordner). Spalten:
`ts,true_distance,depth_m,confidence,lighting`. Aussortierte Sessions (leer,
falsches Ziel, Maßband vergessen) liegen mit Begründung im Dateinamen unter
`data/measurements/m4/verworfen/`.

Braucht ein LiDAR-fähiges Gerät (iPhone Pro-Modelle). Prüfen: LiDAR-Knopf in
der App öffnen — steht dort „LiDAR auf diesem Gerät nicht verfügbar", geht
diese Messung auf dem jeweiligen Gerät nicht.

## Ablauf

Für jede der 7 Distanzen (0,3 / 0,5 / 1 / 2 / 3 / 4 / 5 m), **zweimal**
(einmal Tageslicht, einmal Dunkelheit):

1. Ebene, matte Zielfläche (keine Kante, kein Fenster/Spiegel) senkrecht vor
   das Gerät stellen, Abstand mit Maßband messen
2. App: LiDAR-Knopf → Solldistanz eintragen → Beleuchtung wählen
3. Fadenkreuz auf die Fläche halten, ruhig halten, Start (App stoppt
   automatisch bei 30 Messungen)
4. „CSV exportieren" → Datei sichern

Macht 14 Durchgänge, 14 CSV-Dateien.

Bereich). Belegt die Reichweitengrenze mit einer Messung statt sie nur zu
behaupten — bewusst nicht ausgeschlossen.

## Nach der Messung

Alle CSV-Exporte nach `data/measurements/m4/` legen (Tag- und
Nacht-Dateien gemischt, die Spalte `lighting` unterscheidet sie), dann:

```bash
cd analysis && python -m pytest tests/test_m4_lidar.py -v && python -m evaluation.m4_lidar
```
