# Messprotokoll M1 — statische GNSS-Genauigkeit

Referenzpunkte und deren Herkunft: siehe `data/reference/HERKUNFT.md`.
Rohdaten liegen unter `data/measurements/m1_static/*.csv`
(Spalten: `ts,lat,lon,h_acc,point_id,session`).

Für jede der neun Sessions (3 Punkte × 3 Wiederholungen) eintragen:

| Punkt | Session | Datum | Uhrzeit (Start–Ende) | Wetter | Gerät | iOS-Version | Datei |
|---|---|---|---|---|---|---|---|
| p1 | 1 | | | | | | |
| p1 | 2 | | | | | | |
| p1 | 3 | | | | | | |
| p2 | 1 | | | | | | |
| p2 | 2 | | | | | | |
| p2 | 3 | | | | | | |
| p3 | 1 | | | | | | |
| p3 | 2 | | | | | | |
| p3 | 3 | | | | | | |

Die iOS-Version gehört dazu, weil sich das Positionsfilter zwischen
Versionen ändert.

## Vollständigkeitsprüfung

Nach der Messung, aus `analysis/`:

```bash
for f in ../data/measurements/m1_static/*.csv; do echo -n "$f: "; tail -n +2 "$f" | wc -l; done
```

Erwartet: je Datei 500–700 Zeilen (10 Minuten bei rund 1 Hz). Deutlich
weniger deutet auf Drosselung hin (Energiesparmodus prüfen) — Session
wiederholen.

## Rückfallebene

Falls für einen Punkt keine belastbare Referenzkoordinate beschafft werden
konnte: hier vermerken, für welchen Punkt und warum, und dass M1 für diesen
Punkt auf Wiederholgenauigkeit statt absoluten Versatz ausgewertet wird
(siehe `data/reference/HERKUNFT.md`).
